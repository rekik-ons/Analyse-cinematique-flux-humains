# Analyse cinématique des flux humains

Description
Ce projet consiste à analyser les mouvements et les déplacements des flux humains à partir de données cinématiques, afin d’étudier les trajectoires, les vitesses et les comportements de déplacement.

Organisation
Projet collaboratif réalisé par une équipe de trois étudiants.
